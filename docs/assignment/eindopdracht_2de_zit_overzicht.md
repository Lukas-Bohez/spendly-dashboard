## Deel 1: Design in Figma
Maak een dashboard-design na in Figma op basis van inspiratie van Dribbble of Behance. Het mag geen UI kit zijn.

### Verplichte onderdelen
- Navigatie
- Form element, zoals een zoekbalk of date picker
- Data visualisatie, zoals een bar chart of donut chart
- Grid met verschillende soorten inhoud

### Design system eisen
- Gebruik local variables als design tokens
- Gebruik components met variants
- Gebruik local text styles
- Werk met light en dark theme
- Zorg dat design tokens/primitives overal toegepast worden
- Gebruik auto layout zodat het geheel flexibel blijft
- Responsive uitwerken mag, maar is niet volledig verplicht

## Deel 2: Frontend in React + HTML + CSS
Zet het design om naar een webversie.

### Verplichte frontend eisen
- Accessible opbouwen
- Font-size van de gebruiker respecteren
- Contrast ratio’s in orde
- Hele pagina bedienbaar met toetsenbord
- CSS variables gebruiken op basis van het design system
- Light/dark theme laten volgen via de OS-instelling
- Responsive uitwerken
- CSS grid minstens 1 keer gebruiken
- Minstens 2 onderdelen interactief maken
- Minstens 2 nieuwe CSS features gebruiken uit de leslijst
- Data visualisatie mag ook als svg
- Favicon voorzien

## Indienen
- Figma file als .fig bewaren en indienen
- Frontend in een .zip indienen
- `node_modules` verwijderen uit de zip

## Rubric waar je op beoordeeld wordt
- Design checklist
- Local variables
- Figma file structuur
- Auto layouts
- Afwerking en detail
- Accessibility
- CSS variables
- Code quality
- Interactions
- CSS features

## Praktische aandachtspunten
- Kies eerst inspiratie en toon die tijdens de consultles
- Gebruik geen bestaande UI kit als eindbasis
- Zorg dat je mini design system logisch opgebouwd is
- Leg bij de examenverdediging uit welke 2 CSS features je gebruikt en waarom

## Niet expliciet vermeld in de opdracht
- Er staat geen officiële framerate-eis in de opdracht.
- Als je animaties maakt, is 60 fps een goed praktisch streefdoel.
- Exacte image/video specificaties, viewportbreedtes of bestandsgroottes worden niet genoemd.
