Deel 1: Design

Maak een design van een dashboard na in Figma. Kijk daarvoor op dribbble.com of op behance.net. Pas op, het mag geen UI kit zijn. Zorg dat het design dat je gaat namaken voldoet aan de UI design checklistLinks to an external site. zoals gezien in de les. Het kan zijn dat je een aantal zaken anders zal moeten doen om er aan te voldoen. 
Inspiratie

Zoek eerst inspiratie op dribbble of behance. Maak bv een collection op dribbble met mogelijke kanshebbers. Zoek op bv “dashboard design” of specifieker bv: “transaction dashboard” Stel dit tijdens de consult les voor voor je het begint na te maken.
Verplichte onderdelen

    Navigatie
    Form element (bv zoekbalk of date picker)
    Data visualisatie (bv bar chart, donut chart)
    Grid met verschillende soorten inhoud

Design system

Zorg dat je een mini design system hebt voor je project

    Gebruik design tokens als local variables
    Gebruik components met variants
    Gebruik local text styles

Kijk naar een design system zoals van Atlasion, Polaris of IBM. Welke design tokens gebruiken ze daar en hoe passen ze toe op elementen? 
Vereisten:

    Maak components met variants en aanpasbare properties
    Gebruik local variables. Maak voor de colors base tokens en design tokens zoals bij Atlasian
    Zorg er voor dat je kan switchen van light naar dark theme
    Zorg dat je een design system hebt met design tokens/primitives overal toegepast worden
    Zorg dat je figma file werkt met auto layout zodat alles mooi flexibel is
    Responsive hoef je het niet volledig uit te werken maar mag wel

Deel 2: Frontend

Zet jouw design om naar HTML en CSS met React.
Vereisten

    Zorg dat het accessible is.
        Font-size van de gebruiker wordt gerespecteerd.
        Contrast ratio’s
        De hele pagina is bedienbaar met het toetsenbord
    Gebruik CSS variables op basis van je design system. 
    Zorg dat je kan switchen van light naar dark theme afhankelijk van de instelling van je besturingssysteem.
    Werk het hier wel responsive uit. Denk zelf na hoe en wat er anders moet.
    Gebruik CSS grid minstens 1 keer
    Maak minstens 2 onderdelen interactief. Zorg voor een goede micro interaction met een goede animatie. Pas op: een hover effect telt niet als interaction.
    Pas minstens 2 nieuwe CSS features toe uit deze lijst. Zorg dat je ze kan toelichten op de dag van het examen.
    Data visualisatie mag een svg zijn. Maar kan natuurlijk ook interactief worden.
    Voorzie een favicon.

Indienen

Deadline: dag van het examen

    Dien je figma file in als .fig file. (File > Save As .fig...)
    Maak een .zip van je frontend folder en dien in (verwijder de map node_modules voor het indienen).
